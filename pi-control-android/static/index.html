File trên Pi

Quyền user SSH · root

Bao gồm file ẩn như .env. Sửa văn bản UTF-8 tối đa 512 KiB; lưu tạo bản sao cạnh file gốc. Không tự khởi động lại service.

Chuyển file từ điện thoại

Tối đa 16 MiB/file, gồm .py, .env, ảnh, âm thanh, ZIP. Thư mục đích phải có sẵn. Nếu trùng tên sẽ hỏi ghi đè và tạo bản sao.

Nhập đường dẫn rồi chọn Xem thư mục hoặc Mở file.

Kết nối

Dùng SSH key đã thiết lập trong Termux. Không nhập mật khẩu vào giao diện. Xác nhận host key trong Termux trước lần kết nối đầu.
